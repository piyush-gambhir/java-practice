# Java Practice

Java programming practice — basic syntax exercises, pattern problems, and core language fundamentals.

## Contents

- **Standalone exercises** — array printing, binary-to-decimal conversion, number reversal, digit sum, range printing, etc.
- **`pattern-problems/`** — pyramids, diamonds, hollow triangles, Pascal's triangle variants, alphabet patterns, and other common pattern-printing problems.

## Running

Each file is a self-contained `public class`. Compile and run with `javac` / `java`:

```bash
javac pattern-problems/pascals_triangle.java
java -cp pattern-problems pascals_triangle
```
